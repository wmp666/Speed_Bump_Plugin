# 每日金句
一款通过系统托盘通知，在「软件启动时」或「每日固定时间点」向您推送一句金句的小插件。

## 功能
- 金句内容读取自带文本 `com/wmp/resource/text.txt`（每行一句），可直接编辑追加。
- 两种显示方式（可在插件设置页中配置）：
  - 启动时：软件启动后推送一次；
  - 固定时间点：支持多个，使用英文分号 `;` 分隔，如 `09:00;12:30;21:00`。
- 通知通过系统托盘图标（`Downloader.trayIcon`）弹出，不干扰主界面。

## 设置项说明
- `great_juzi.show_way`：显示方式，`start` = 启动时显示，`time` = 固定时间点显示。
- `great_juzi.show_times`：仅当显示方式为 `time` 时生效，填写时间点，分号分隔。

## 注意
- 仅用于个人学习交流。
