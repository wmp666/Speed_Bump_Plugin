# 图片格式转换器
- 支持读取的格式：cur, tiff, wbp, bmp, xwd, pntg, gif, tf8, pic, btiff, rgbe, mac, tif, wmf, xyze, ico, btf, dcx, wbmp, jpeg, pict, jpg, pct, pcx, svg, png, rle, webp, icns, dds, hdr, emf
- 支持写入的格式：jpg, pct, tiff, bmp, gif, tf8, png, rle, btiff, icns, tif, ico, btf, jpeg, wbmp, pict
- 同时支持读写的格式：tiff, bmp, gif, tf8, btiff, tif, ico, btf, wbmp, jpeg, pict, jpg, pct, png, rle, icns

## 使用方法
- 将图片拖入填写链接文本框中，或者在其中写文件路径

## 注意
- 受到第三方库影响，可能存在部分问题
