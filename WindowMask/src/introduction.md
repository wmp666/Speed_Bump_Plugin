# 窗口遮挡
一款在检测到指定窗口出现时，把它「盖住」并显示自定义文字的小插件 —— 拿来挡住摸鱼窗口、提醒自己专注都很顺手。

## 功能
- 持续检测**所有顶层窗口的标题**（每 0.2 秒一次），标题中包含你配置的任意一段文字即视为命中。
- **不依赖窗口是否获得焦点**：只要窗口还在，后台窗口同样会被遮挡；可以同时遮挡多个窗口。
- 匹配文字支持多个字段，使用英文分号 `;` 分隔，例如 `bilibili;抖音;Steam`。
- 命中后在该窗口原位置生成一层**遮罩**，恰好盖住这个窗口并显示你配置的文字；窗口移动或缩放时遮罩跟随。
- 遮罩会接收鼠标操作，被遮挡期间无法点击下面的窗口；窗口关闭、被最小化或标题不再匹配时遮罩自动消失。
- 遮罩保持在目标窗口**正上方**（不使用粗暴的全局置顶），因此后台窗口的遮罩不会浮到最前面挡住你正在使用的其他窗口；若层级调整失败会暂时置顶兜底，确保遮挡一定看得见。

## 设置项说明
- `window_mask.enable`：是否启用窗口遮挡，默认启用。
- `window_mask.match_text`：匹配文字，多个用英文分号 `;` 分隔；留空则插件不做任何事。
- `window_mask.display_text`：遮挡时显示的文字，可用 `\n` 表示换行；留空则只显示纯色遮罩。

## 注意
- 仅支持 **Windows**（依赖 `user32.dll` 读取窗口标题与位置，通过 JDK 25 正式 FFM API 调用，无需额外依赖）。
- 单次最多同时遮挡 8 个窗口（匹配文字过于宽泛时会有日志提示）；被最小化的窗口不遮挡。
- 出于安全考虑，**减速带自身的窗口永远不会被遮挡**，避免把自己锁死后连设置页都点不到。
- 仅用于个人学习交流。
